# Salon accessibility checks

For every client-facing page:
- Use a logical heading hierarchy.
- Associate visible labels with form controls.
- Keep keyboard focus visible.
- Provide meaningful button and link text.
- Ensure interactive controls can be operated without a mouse.
- Check readable contrast for text over photography and decorative backgrounds.
- Verify forms expose clear validation messages.

Run these checks on Home, Services, Bookings, and Contact before release.
