# Salon asset review checklist

Before releasing visual changes:

- Verify every stylesheet and script path resolves from a fresh session.
- Check external image and font dependencies for broken resources.
- Confirm image backgrounds remain readable with overlaid text.
- Test cards, forms, and navigation on mobile and desktop.
- Remove obsolete page assets when a feature is deleted.

Open Home, Services, Bookings, Contact, and Staff pages after any shared asset change.
