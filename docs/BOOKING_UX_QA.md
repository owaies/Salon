# Salon booking UX QA

Verify the booking journey from navigation to confirmation.

## Flow
1. Open the booking page from the main navigation.
2. Confirm available appointment information is understandable.
3. Submit valid booking data.
4. Verify successful feedback is visible.
5. Reload and confirm the expected appointment state is preserved.

## Rejection cases
Test missing required fields, invalid values, unavailable time slots, and backend failures.

## Mobile
Repeat the flow at a narrow viewport and check that controls remain usable without horizontal scrolling.
